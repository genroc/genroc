Processes can expose a task to be solved by human or machine.

External task works in a similar way as a child task,
it can have specified input and result_schema.
It parks the process until it a result is submited.

## Example

```genroc-lsp
# approval.genroc.yaml
name: approval
input_schema:
  type: object
  properties:
    amount: {type: integer}
  required: [amount]

tasks:
  - id: review
    action:
      type: external
      input:
        amount: "$: input.amount"
      result_schema:
        type: object
        properties:
          approved: {type: boolean}
        required: [approved]
    output: "$: self.result.approved"
    switch: end

output:
  approved: "$: outputs.review"
```

Let's apply the example process and run it.

```sh
> genctl apply                       
latest: approval v1 (current)

> genctl run approval --set amount=10
started: 5fy765kh  approval@v1  (running)
```

If we get the state of the process after it started,
we'll see it has `Phase: external` (`phase` in the API).

```sh
> genctl get @last                   
ID:       5fy765kh
Process:  approval@v1
Status:   running
Task:     review
Phase:    external
```

We can resolve the task through cli with `resolve` command.

```sh
genctl resolve @last --task review --set approved=true
resolved: 5fy765kh  task=review  (delivered)
```

Once resolved, the process continues it's execution to completion.

```sh
> genctl get 5fy765kh                                      
ID:       5fy765kh
Process:  approval@v1
Status:   completed
Task:     review
Created:  2026-09-24 14:23:27
Updated:  2026-09-24 14:44:51

Output:
approved: true
```

## Listing processes waiting for resolution

You can filter process which are waiting for external resolution
with the regular instances command.

```sh
> genctl instances --phase external
ID        STATUS            PROCESS      UPDATED  CREATED  CODE  ERROR
3kjfx4vm  running·external  approval@v1  1m ago   1m ago         
02pcayvt  running·external  approval@v1  1m ago   1m ago         
4cqpdx8z  running·external  approval@v1  1m ago   1m ago         
8nte1end  running·external  approval@v1  1m ago   1m ago
```

## Queues

If we want to resolve external tasks in a systematic way,
we need to have a queue and workers resolving the tasks.

We could use instances filter and pick the process we want to
resolve, but that is problematic when we have multiple workers
 - they need to know which process is already taken.

Genroc offers an API for this. Let's demonstrate the API
by showing how to create a custom external worker.
